# Módulo 8: Estruturas de Dados Persistentes ⏳🧱

Neste módulo, introduziremos o fascinante conceito de estruturas de dados persistentes. Diferentemente das estruturas efêmeras que modificam seu estado atual, as estruturas persistentes preservam todas as versões anteriores de si mesmas cada vez que são modificadas.

## Tópicos principais:

*   O que são estruturas de dados persistentes e por que são úteis?
*   Níveis de persistência (parcial, total, confluente).
*   Técnicas para alcançar a persistência.
*   Exemplos práticos: listas encadeadas persistentes, árvores de busca persistentes.
*   Aplicações em sistemas de controle de versão, programação funcional e mais.
*   Estruturas de dados imutáveis e sua relação com a persistência.

Prepare-se para entender como manter o histórico de suas estruturas de dados de forma eficiente!
